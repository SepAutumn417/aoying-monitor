# 熬鹰资本监控系统

自有服务端与 Web 界面（安卓 App 后续开发），持续跟踪熬鹰资本的多平台观点、动态和仓位变化，辅助用户自行决策。

## 核心范围

- Telegram：禁言群、聊天群重点本人发言、交易信号话题、消息通知群。
- X、Fomo、OKX：先核实账号入口和可获取范围，再逐个接入。
- 仓位：监听新消息与编辑，比较快照，识别开仓、加仓、减仓、平仓；价格和浮盈刷新不重复提醒。
- 安卓 App：仓位、动态、变化记录、连接状态；后台加密长连接、断线补收、声音和振动、手动停止与确认。
- 后续 AI：基于出处生成交易对关注清单；当前不接入外部模型，不执行自动交易。

## 当前状态

本仓库目前是规划及通用 HTTPS 基础设施，尚无业务服务端或安卓应用实现。旧系统与 Gotify 已从服务器移除，当前没有运行中的业务监控。保留的 HTTPS 入口返回404，不能当作应用已经上线。

下一阶段先完成服务端与Web基础，再逐一实现真实来源监控；这些能力完成后再规划安卓App。不承诺后台强行停止、断网或关机时仍能即时接收。

## 隔离与隐私

项目目录 F:\aoying-monitor；独立仓库与服务器目录 /opt/aoying-monitor。旧代码仅供参考，不迁入旧凭证、数据库或登录会话。
业务消息不经第三方通知 SaaS。HTTPS 保护传输，不代表端到端加密；自有服务器仍能读取采集内容。密码、设备令牌和运行数据禁止提交仓库。
