# Phase 1 — Web 界面与交互规范

本文是供用户确认的推荐设计，不代表用户已确认视觉风格或已开始实现。范围仅 AUTH-01、DATA-01、WEB-01、OPS-01；后续仓位业务、AI、下单、安卓提醒均不在本阶段。

## Design System

| Property | Value |
|---|---|
| Tool | none；手工 CSS 变量和少量共享组件，待方案批准后实施 |
| Preset | not applicable |
| Component library | none proposed |

## 页面与信息架构

路由建议：`/login`、`/timeline`、`/events/:id`、`/status`。登录成功默认进入时间线；受保护深链接在会话有效时可直接打开，无效时先登录，再回同源合法相对路径，不能接受任意外部跳转地址。

### 登录

单账号登录表单，标题“熬鹰监控”，说明“登录后查看你的监控记录”。用户名、密码有常驻可见标签；密码默认遮蔽，可切换显示，允许密码管理器自动填充。提交按钮“登录系统”，提交时禁用重复提交并显示“正在登录…”。不显示注册、营销、重置密码或第三方登录入口；账号由服务器管理员安全配置。

登录错误统一为“账号或密码不正确，请重新输入。”，避免泄露账号是否存在。限频显示“尝试次数较多，请稍后再试。”；网络失败显示“无法连接服务器，请检查网络后重试。”。不在页面或日志回显密码、令牌和服务端堆栈。

### 时间线

信息记录正文是主视觉焦点，页头和元数据次之；来源状态不与正文争抢注意。

顶栏含产品名、当前页面、更新时间和“退出登录”。主导航只有“信息时间线”“监控状态”，不要展示尚未实现的“交易”“AI”“App”等入口。

页头“信息时间线”，副说明“查看已保存的信息及其原始依据”。工具栏提供已存在来源的筛选、清除筛选和“刷新记录”；不显示四个平台全都已接入的假筛选。无来源时禁用来源筛选并有说明。按服务端稳定游标分页，底部“加载更早记录”；不显示未经服务端证明的总条数或无限滚动动画。

一条记录包含：类型文字、来源/话题、作者（缺失显示“作者未知”）、源时间、采集时间、正文摘要和“查看详情”。测试记录始终有可见“测试数据”标记，不能仅用颜色区分。摘要最多四行；完整原文在详情，不通过 tooltip 才能访问。

页面更新不能抢走键盘焦点或把用户拖回顶部。默认首次展示最新记录；用户正在阅读较早记录时，有更新只提示“有新记录，点击查看”，不直接插入造成滚动跳跃。更新方式最终由技术研究确定；无论轮询还是实时连接，都显示最近一次成功更新时间。

### 详情与原文版本

独立页面，提供“返回时间线”。顶部重复来源、作者、源/采集时间、类型及测试标记；正文按纯文本原样保留换行，长单词可断行。禁止直接渲染来源 HTML、脚本、内联事件或远程媒体，第一阶段不加载外部图片。

“原文版本”区列出版本号、源编辑时间（缺失明确未知）、采集时间，选择后展示对应文本。一个版本时显示“当前仅保存 1 个版本”；没有关联原文时显示“此事件暂无关联原文”，不能伪造版本。阶段1以合成编辑样本证明保存与追溯，不呈现未实现的真实仓位差异算法。

外部原文链接仅允许服务端/前端验证后的 http/https，明确标为“打开原始来源（新窗口）”；使用 `noopener noreferrer`，不发送完整页面 referrer。非网络协议或不合法 URL 不生成链接。任何 ID 不存在显示“记录不存在或不可访问”，提供返回列表，不泄露其是否属于别的主体。

### 来源与系统状态

标题“监控状态”。“来源状态”表列出计划中的 Telegram、X、Fomo、OKX，当前均显示“未接入”；这些是状态行，不是配置 CRUD。无实际连接时最后采集时间为“尚无采集记录”，禁止绿色“运行正常”。

“系统状态”只展示当前用户需要判断服务是否可用的信息：服务版本、最近成功查询时间、数据存储可用性、更新时间；不暴露绝对文件路径、环境变量、凭证、数据库连接串、详细系统进程。后端健康与来源监控独立呈现：服务可用不代表平台已接入。

## 页面布局与响应式

- 桌面 ≥1024px：顶栏64px；主区域最大宽度1200px、水平居中、左右32px；导航与内容分离，导航宽192px，内容占剩余。列表以单列信息卡呈现，不做多栏瀑布流。
- 768–1023px：左右24px，导航移到顶栏下方的两个文字标签，信息内容仍单列。
- <768px：左右16px，顶栏可换行；筛选和按钮换行，表单满宽，状态表转为按来源分组的定义列表。44px最小触摸目标通过48px控件高度满足。
- 登录卡宽400px，窄屏为可用宽度；页面垂直居中，但小屏或软键盘出现时允许文档正常滚动。
- 在360px宽和200%浏览器缩放下无整页横向滚动；原文/长URL使用 `overflow-wrap:anywhere`；不能缩小字到不可读。

## Spacing Scale

| Token | Value | Usage |
|---|---|---|
| xs | 4px | 标签内部、图标与文字 |
| sm | 8px | 同组元素、元数据 |
| md | 16px | 字段间距、卡片内段落 |
| lg | 24px | 卡片与表单内边距 |
| xl | 32px | 桌面内容边距、区域间距 |
| 2xl | 48px | 按钮/输入最小高度、主区分隔 |

Exceptions：仅1px边框与2px焦点轮廓是绘制细节，不是布局间距。控件圆角8px、卡片12px，全部为4的倍数。

## Typography

只使用14、16、20、28px四档；字重只使用400和600。

| Role | Size | Weight | Line Height |
|---|---|---|---|
| Body / inputs | 16px | 400 | 1.5 |
| Label / metadata | 14px | 400；状态及字段名600 | 1.5 |
| Section heading | 20px | 600 | 1.2 |
| Page heading | 28px | 600 | 1.2 |

时间与数量可用系统等宽回退显示、`font-variant-numeric:tabular-nums`，不新增字号。正文始终左对齐。存储UTC，界面转用户浏览器时区，并在页面首次明确“时间按 Asia/Hong_Kong 显示”等实际时区；详细时间可展开显示含时区的完整值，不能仅依赖“几分钟前”。

## Color

| Role | Value | Usage |
|---|---|---|
| Dominant (60%) | #F5F6F8 | 页面底色与大片空白 |
| Secondary (30%) | #FFFFFF | 卡片、表单、顶栏 |
| Accent (10%) | #1D4ED8 | 登录/刷新主按钮、当前导航、可点击详情链接、焦点轮廓 |
| Destructive | #B42318 | 本阶段无数据删除；保留给未来破坏性操作，禁止用作一般强调 |

文本 #172033；次要文本 #475467；边框 #D0D5DD。故障状态使用独立语义色 #9A3412 与淡底 #FFF7ED，不能把故障等同破坏操作。普通状态和“未接入”用中性色；已验证健康状态可用 #166534，但不用于尚未接入的平台。

Accent reserved for：提交登录、刷新主动作、当前导航、详情链接和键盘焦点，不给所有卡片/全部元数据上蓝色。60/30/10是视觉占比目标，不强制每个屏幕精确面积。状态同时有文字，不依赖红绿区分。对比度按正文至少4.5:1、控件与焦点至少3:1检查；不以色值声明代替实测。

## 状态表

| 状态 | 页面行为 | 恢复动作 |
|---|---|---|
| 首次加载 | 保留标题与导航，内容区显示“正在加载记录…” | 无重复提交 |
| 真正空列表 | 使用空态文案，不显示错误 | 刷新记录 |
| 筛选无结果 | “没有符合筛选条件的记录” | 清除筛选 |
| 请求失败且无缓存 | 显示失败原因摘要，不显示“暂无数据” | 重新加载记录／重新加载详情 |
| 请求失败且有旧数据 | 保留旧记录，明显标注“更新失败，当前显示此前保存的结果”和成功更新时间 | 重新加载记录 |
| 部分元数据缺失 | 使用“未知/未提供”，保留其余正文 | 查看详情，无静默补造 |
| 未接入来源 | “未接入”，时间“尚无采集记录” | 本阶段无伪连接按钮 |
| 会话过期 | 清除当前敏感视图并回登录，提示会话过期 | 重新登录 |
| 退出失败 | 不宣称退出成功，提示重试；成功后清除敏感缓存 | 重试退出登录 |

## Copywriting Contract

| Element | Copy |
|---|---|
| Primary CTA | 登录系统；时间线主动作：刷新记录 |
| Empty state heading | 暂无监控记录 |
| Empty state body | 当前尚未接入真实来源。测试记录会标注“测试数据”；可刷新查看已保存内容。 |
| Filter-empty | 没有符合筛选条件的记录。清除筛选后再试。 |
| Error state | 无法加载记录，请检查连接后重试。 |
| Partial stale data | 更新失败，当前显示此前保存的结果。上次成功更新：{含时区时间}。 |
| Synthetic marker | 测试数据 · 非真实监控信息 |
| Not integrated | 未接入；尚无采集记录 |
| Auth expired | 会话已过期，请重新登录。 |
| Logout | 退出登录；成功后回登录页，不显示“退出成功”后仍留敏感内容 |
| Missing detail | 记录不存在或不可访问。返回时间线。 |
| Refresh success | 已更新至 {含时区时间}，不夸大为“所有平台实时在线” |
| Destructive confirmation | 本阶段无删除、清空、交易或撤销入口；不存在破坏性确认框 |

错误给用户下一步，不把状态码、堆栈和部署路径当产品文案。与登录有关的用户输入错误就地显示；成功/失败反馈使用适当 `aria-live`，不反复朗读后台每次刷新。

## 可访问性与交互约束

语义化 `<form>`、`<label>`、按钮、链接、`nav`、`main`；提供“跳到主要内容”链接。焦点轮廓为2px实线蓝色、2px外偏移，禁止 `outline:none`。Tab顺序随视觉顺序，Enter提交表单，按钮支持键盘，路由变化后焦点到主标题。每个输入有独立可见标签，错误用 `aria-describedby` 关联。

所有交互目标至少48×48px；选项/链接在紧密列表中通过块级区域补足，不能覆盖相邻动作。无hover专属功能、自动播放声音、炫目动画或强制全屏；`prefers-reduced-motion`关闭非必要过渡。登录表单在软键盘打开时不遮挡提交按钮。
