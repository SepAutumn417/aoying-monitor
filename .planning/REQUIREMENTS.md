# Requirements: 熬鹰资本监控

**Defined:** 2026-10-30
**Core Value:** 真实仓位变化及时到达手机并提醒，可追溯而不误报。

## v1 Requirements

- [ ] **AUTH-01**: 手机使用独立设备凭证认证，设备间事件隔离且撤销后已有连接失效。
- [ ] **DATA-01**: 事件持久化去重，服务/App重启后按连续游标补齐；正常重放不重复响铃，崩溃恢复识别持久化提醒状态并显示待处理项。
- [ ] **ACK-01**: 界面区分服务器接收、设备落库、用户已知晓，停止响铃不等于已交易。
- [ ] **APP-01**: K50无VPN在Wi-Fi/移动网络接收合成事件，显示连接与断线原因。
- [ ] **ALERT-01**: 每次有效新事件声音振动可测、持续提醒可手动停止，过期补收不误作实时。
- [ ] **OPS-01**: 可信HTTPS/WSS、证书续期、非root服务和凭证脱敏经验证。
- [ ] **TG-01**: 四话题按稳定ID采集，本人和助理与普通讨论区分，原文来源可追溯。
- [ ] **TG-02**: 同一仓位消息编辑经监听和周期核对识别开加减平，价格/浮盈刷新不误报。
- [ ] **TG-03**: 采集断线/重启恢复，原始版本和待通知事件事务保存，失败可查询。
- [ ] **UI-01**: 手机查看当前仓位、变化历史、观点动态、原文及连接/提醒设置。
- [ ] **UI-02**: 同笔操作跨来源关联，仅充分证据时去重；未知/失败/无数据分别显示。
- [ ] **X-01**: 核实授权入口后监控本人推文，时间与原文可追溯，限频/回填行为实测。
- [ ] **FOMO-01**: 核实平台账号/地址后监控公开可获取交易仓位，缺失字段不伪造。
- [ ] **OKX-01**: 核实公开入口/权限后监控可获取订单仓位，不宣称能读取私人订单。
- [ ] **OPS-02**: 数据库备份恢复、容量/保留期、来源失联/设备离线及整机探活可查。
- [ ] **PRIV-01**: 设备撤销、锁屏隐私、日志/备份/密钥边界经审查，未实现加密不作承诺。
- [ ] **E2E-01**: 在K50完成至少24小时100条测试并报告到达、延迟、声音和离线补收证据。

## v2 Requirements

- **AI-01**: 基于原文和仓位历史提取交易对、倾向、触发/失效条件及引用，标注推断。
- **AI-02**: 先确认外部模型披露边界并建立人工样本评估，失败不阻塞采集。

## Out of Scope

自动交易、Gotify、第三方通知SaaS、未经验证的厂商推送资格、把博主私有订单可见性当成既定能力。
