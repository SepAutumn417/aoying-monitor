# TG 原始信息监控收口

用户已确认不需要消息推导的仓位账本。

- Web：移除账本 Provider、持仓展示与入口，旧入口导向 TG 消息中心，总览直接使用 TG 原文。
- Android：移除推导账本页面与加载，复用 TG 原文及最新快照，不改原生后台提醒协议。
- 后端：采集只存消息/修订/删除状态；新消息的动作提醒仅逐条解析原文，不生成 Signal、Position、PositionEvent。历史回补静默，增量新消息提醒，重复和编辑不重复响铃。
- 历史账本数据不删除；旧跟单库/API保留为暂不使用的历史兼容代码，不接入监控路径。
- 验证：先添加禁止自动生成账本的失败测试，再解除耦合；更新已过时的集成断言，运行后端回归、Web测试及构建、可用的Flutter检查。无生产部署/数据库清理/自动跟单。
