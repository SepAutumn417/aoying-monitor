## 怎么自己验证

### 1. 后端

```bash
cd backend
python -m pytest
python -m uvicorn app.main:app --port 8000
```

另开一个终端：

```bash
python -c "import httpx;print(httpx.get('http://127.0.0.1:8000/healthz').json())"
```

期望：`{'status': 'ok', 'service': 'aoying-monitor', 'version': '0.1.0'}`

### 2. Web

```bash
cd web
npm install --ignore-scripts --no-audit --no-fund
npm test
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`，应看到深色总览页：左侧导航、顶部“本地骨架 · 未连接生产数据”、
四张数据源卡（Telegram/Binance/OKX/fomo，均标“未连接”）、最新事件空状态、增量路线 I0–I8。

### 3. Android

```bash
cd app
flutter test
flutter run --dart-define=API_BASE_URL=http://<你的局域网IP>:8000
```

模拟器可省略 `--dart-define`（默认 `http://10.0.2.2:8000`）。
应看到：深色登录页 → 点“预览骨架” → 底部五栏可切换，总览页显示“系统骨架已就绪”。

> 本机暂无 Java/Android SDK，I0 未构建 APK；`flutter test` 与 `dart analyze` 已通过。
> 装好 Android SDK 后 `flutter build apk --debug` 即可出包。

## 已知限制（不影响验收，但需要知道）

1. **中文路径**：工作目录含中文，Flutter 的 `impellerc` 无法处理，本地构建需通过 ASCII 联接
   `F:\aoying_ws` 与 `F:\aoying_flutter` 访问（已创建，指向同一份文件，不复制）。
2. **沙箱**：Vite/Vitest/Flutter 需要管道子进程，受限沙箱下会 `EPERM`，本地构建需放宽执行权限。
3. **无 Android SDK**：本机未装 Java/Android SDK/adb，I0 只验证到 `flutter test`；出 APK 放到 I1。
4. **无数据库**：`backend/app/db.py` 只是引擎占位，未连接 Postgres；I1 起接 Alembic 迁移。
5. **Web 无鉴权**：`/login` 是静态占位，任何路由都能直接访问；I1 加路由守卫。
6. **Docker 未验证**：本机 Docker daemon 未运行，`docker-compose.yml` 尚未实跑，部署在 I1/I2 一起验证。
