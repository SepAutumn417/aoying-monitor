## 第二轮：按反馈重做信息架构

第一轮交付被否，原因是「UI 风格、信息密度、栏目划分需要优化」，且总览把「模块接入状态」当成主角。本轮的具体改动：

1. **总览从「骨架说明页」改成「数据主展示页」**：顶部 4 张 KPI（总名义仓位 / 未实现盈亏 / 今日已实现 / 今日仓位变化）→ 场所分布占比 → 当前持仓表 + 仓位变化流 → 最新发言 + 最新提醒 + 关注标的。
2. **删掉所有纯说明性文字**：不再有「熬鹰资本的交易动作与公开发言，最终会汇入同一条时间线」这类介绍句，也没有「系统骨架已就绪」「增量路线 I0–I8」占据首屏。
3. **接入状态收进「数据源」页**，总览不再出现 `未连接` 一类的占位块。
4. **栏目重命名**：`时间线` → `发言`（观点/互动/仓位播报按来源聚合），`告警` → `提醒`，新增独立 `数据源`。
5. **数字自洽**：KPI、场所占比、持仓合计都由同一份持仓数据聚合算出来，不存在硬编码的大数字。
6. **列表可筛选**：持仓按场所、发言按来源、提醒按等级，均带关键词搜索（Web）。

示例数据全部集中在 `web/src/lib/demo.ts` 与 `app/lib/data/demo.dart`，页面右上角有 `示例数据` 徽标；接入真实数据源后整块替换。

## 怎么自己验证

### 1. 后端

```bash
cd backend
python -m pytest
python -m uvicorn app.main:app --port 8000
```

另开一个终端：

```bash
python -c "import httpx;print(httpx.get('http://127.0.0.1:8000/healthz').json())"
```

期望：`{'status': 'ok', 'service': 'aoying-monitor', 'version': '0.1.0'}`

### 2. Web

```bash
cd web
npm install --ignore-scripts --no-audit --no-fund
npm test
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。应看到：左侧窄导航（总览/持仓/发言/提醒/数据源/设置），
总览首屏是四张 KPI 卡片与持仓表，右上角有「示例数据」徽标。

### 3. Android

```bash
cd app
flutter test
flutter run --dart-define=API_BASE_URL=http://<你的局域网IP>:8000
```

模拟器可省略 `--dart-define`（默认 `http://10.0.2.2:8000`）。
应看到：深色登录页 → 点「进入监控台」→ 底部五栏可切换，总览首屏是 KPI 与持仓表。

> 本机暂无 Java/Android SDK，I0 未构建 APK；`flutter test` 与 `dart analyze` 已通过。
> 装好 Android SDK 后 `flutter build apk --debug` 即可出包。

## 已知限制（不影响验收，但需要知道）

1. **中文路径**：工作目录含中文，Flutter 的 `impellerc` 会把 ASCII 联接解析回真实中文路径，
   因此 `flutter build` / `flutter test` 必须把 SDK 放到纯 ASCII 目录（如 `F:\aoying_sdk\flutter`）。
2. **沙箱**：Vite/Vitest/Flutter 需要管道子进程，受限沙箱下会 `EPERM`，本地构建需放宽执行权限。
3. **无 Android SDK**：本机未装 Java/Android SDK/adb，I0 只验证到 `flutter test`；出 APK 放到 I1。
4. **无数据库**：`backend/app/db.py` 只是引擎占位，未连接 Postgres；I1 起接 Alembic 迁移。
5. **Web 无鉴权**：`/login` 是静态占位，任何路由都能直接访问；I1 加路由守卫。
6. **Docker 未验证**：本机 Docker daemon 未运行，`docker-compose.yml` 尚未实跑，部署在 I1/I2 一起验证。
7. **示例数据**：仓位/发言/提醒全部是 Mock，用于确认信息架构与数字口径，不代表熬鹰真实持仓。
8. **移动端截图方式**：Edge `--headless=new --window-size=390,844` 会被浏览器最小窗口宽度（约 500px）拉到 500+ 再裁左侧 390px，
   产生「右侧贴边 / 底部第 5 项被裁」的假象。真机视口必须走 CDP `Emulation.setDeviceMetricsOverride`，
   脚本在 `.tools/shot.mjs`。本文件里的移动端结论均以 CDP 截图为准。
9. **界面不出现开发代号**：I0–I8 只存在于文档与提交信息，App/Web 上不再出现 `I2`、`骨架`、`待 I1` 一类字样。
