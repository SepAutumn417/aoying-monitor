# P1：自有安卓 App 最小闭环验收

状态：待实现；Gotify测试不算自有App验收。

## 实现范围

服务端发送带event_id、sequence、source_time的合成事件，支持认证WSS、断线游标补收与回执。
App本地持久化后回传收到状态；用户点击已知晓单独回传。事件重复不重复响铃。
App展示连接状态与最近测试事件，提供声音/振动、持续响铃、停止按钮；安全上限与多个事件并发响铃规则实施前明确。
不接真实交易，不接AI，不需要交易所凭证。

## 设备测试矩阵

记录K50系统及App版本、通知/音量/勿扰/后台设置，服务器及手机时间差。

| 场景 | 验证 |
|---|---|
| Wi-Fi/移动网络，VPN关闭 | 数量、端到端延迟、声音振动 |
| 锁屏、至少两小时待机 | 到达、响铃与停止 |
| 清理最近任务 | 后台连接表现，与强行停止分开记录 |
| 断网再恢复、切网 | 自动重连、游标补收、数量顺序 |
| App/服务正常重启 | 游标/本地记录/队列恢复 |
| 重复、乱序及多事件 | 去重、顺序与响铃行为 |
| 过期、编辑、行情刷新样本 | 延迟标记，不把旧信号当实时操作 |
| 凭证错误/撤销/证书异常 | 拒绝连接，错误可见，不降低TLS校验 |

建议至少24小时、100条序号测试；正常在线场景到达率目标100%、P95≤5秒，具体阈值实施前锁定。离线单独统计。
服务器发出、设备收到、用户确认分别计时；HTTP200不算设备到达。
强行停止/关机不要求仍能收信，但恢复后须显示缺口与补收结果。
